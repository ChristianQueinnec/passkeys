# The Passkeys project

The Passkeys project aims to produce a webapp mimicing Keepass.
Keepass (and its derivates Keepassx, Keepassxc, etc.) is great but
does not work equally on MacOS, Linux, Android, etc. so I want to
create a webapp with nearly equivalent capabilities. 

Passkeys is a Progressive Web App (PWA), it runs on modern browsers.
You can install it on your desktop or tablet or phone. It is not as
secure as Keepass but sufficient (for me) if you trust your device.

## Installation

Passkeys is provided as source code but also as a Docker container.
